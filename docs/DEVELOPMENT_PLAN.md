# 개발 단계별 소프트웨어 구현 계획

> 기간과 성능 기준은 **제안 목표**이며 실제 측정 결과가 아닙니다.

| 단계 | 제안 기간 | 구현 범위 | 검증 및 완료 조건(제안) |
|---|---|---|---|
| 프로토타입 | 1–6주 | 모의 센서 입력, 낙상 의심 규칙, 복약 일정, 안내 스크립트 | 핵심 시나리오 데모 실행 및 단위 테스트 통과 |
| 알파 | 7–12주 | 실제 센서 어댑터, ROS 2 노드, 이벤트 통합, 비상 정지 연계 | 통합 테스트·장애 주입·정지 동작 검증 |
| 베타 | 13–18주 | 동의 기반 시범 운영, 접근성 개선, 기록·보호자 알림 | 사용자 테스트, 오탐/미탐 분석, 개인정보 점검 |
| 릴리즈 | 19–22주 | 배포 설정, 버전 관리, 업데이트·롤백, 운영 매뉴얼 | 보안·안전성 심사 및 현장 승인 |
| 운영·개선 | 이후 | 로그 모니터링, 장애 대응, 업데이트, 회귀 테스트 | 정기 점검과 피드백 반영 |

## 실제 구현 전 필수 작업

1. 하드웨어/OS/ROS 2 배포판을 확정하고 센서·모터 인터페이스를 구현한다.
2. 영상 낙상 감지 모델을 수집·검증하고 센서 융합과 사용자 확인 절차를 마련한다.
3. Nav2, 지도 작성, 위치 추정, 장애물 감지, 물리적 비상 정지 및 안전 정지 회로를 구현한다.
4. 음성 인식·합성, OCR/Tesseract 설치, 접근성 평가를 수행한다.
5. 보호자 인증·연락 동의·보안 통신·저장 데이터 최소화·삭제 정책을 수립한다.
6. 사용자 안전성, 의료·개인정보 관련 법규 및 실제 주거환경 시험을 검토한다.

## 권장 패키지와 적용 범위

- `numpy`, `opencv-python`, `mediapipe`: 영상·자세 분석 (옵션 `vision`)
- `APScheduler`: 복약 일정 예약 (옵션 `medication`)
- `pyttsx3`, `SpeechRecognition`: 음성 안내/인식 (옵션 `speech`)
- `Pillow`, `pytesseract`: 키오스크 OCR (옵션 `kiosk`; Tesseract 별도 설치)
- `requests`, `python-dotenv`: API 통신·환경 설정 (옵션 `api`)
- `pytest`, `ruff`: 테스트·코드 품질 (옵션 `dev`)
- `rclpy`, Nav2: ROS 2 환경에서 별도 설치·연동 필요
- `sqlite3`, `asyncio`, `logging`: Python 표준 라이브러리

현재 저장소는 위 선택 패키지를 실제 센서와 연결하지 않습니다. 기본 예제는 표준 라이브러리만 사용합니다.
