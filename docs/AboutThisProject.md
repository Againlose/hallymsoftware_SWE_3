# 프로젝트 개요
노인을 위한 컴페니언 로봇의 구현입니다.
이 프로젝트를 통해 단순 개발론적 방법을 넘어, 실제 팀 프로젝트를 진행할 때 고려하게될 수익성, API 호출, 비즈니스 계획서, URD 등을 종합적으로 고려하게 됩니다.
4인 개발 진행중이며, 이 문서를 작성한 유저는 3번 개발자 입니다.
    스마트 홈 컨트롤, BRD 작성, PRD 작성을 담당합니다.(가정 돌봄로봇 모듈 확장 UML 다이어그램.png 참고)

## 하드웨어
터치 스크린 키오스크 + 이동 가능한 바퀴달린 로봇으로 구성
해당 키오스크는 사용자를 위한 종합 설정 + 옵션과 충전 스테이션을 담당합니다.
    - 다만, 이 프로젝트는 소프트웨어 개발론을 중점으로 다루며, 물질적인 실현은 없습니다. 가상의 시나리오 데이터 Input, 그에 상응하는 Output만 있으면 됩니다.

## 소프트웨어에 대해
바퀴달린 로봇을 위한 소프트웨어, 충전 센터 겸 키오스크를 위한 소프트웨어로 두 갈래 길로 구분 가능합니다.
상세 기능은 가정 돌봄로봇 모듈 확장 UML 다이어그램.png에 나와있습니다.

# 팀 리더
3번 개발자는 팀 리더지만, 아직 팀을 지휘한 적이 없습니다.
원활한 프로젝트 진행을 위해 업무 분담 조언, 리펙토링 조언, xx관점에서의 접근 등을 자유롭게 제시하되, 주 출력으로 이 내용을 쭉 내뱉지는 마세요.
    대신, 별도의 "팀조언.md" 파일을 생성해 그곳에 조용히 적고 보관하십시오.

# Dear Agent
프로젝트 진행 중 기록해야할 함수나 종속성, 호출 규약 등의 다른 개발자들이 참고할 수 있는 기능 문서, 그리고 설정&정의 등의 문서를 건내받은 경우, resource 디렉토리에 넣고 .gitignore에 추가합니다.
    - **지금 이 파일에 한해 .gitignore에 추가하지 마세요. 이 파일은 팀원과 공유해야 합니다.**
    - AI 친화적으로 문서를 작성하고 진행사항에 맞춰 수시로 확인하고 정정하세요. 모든 것을 context window에 넣고 관리하면 블랙박스 문제와 환각 문제가 심해질 수 있습니다.
    - .gitignore의 적절한 관리를 통해 민감 서류가 외부에 노출되지 않음을 기대할 수 있습니다.
