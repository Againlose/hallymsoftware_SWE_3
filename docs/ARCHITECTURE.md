# 아키텍처

```text
RobotController (위험 이벤트 우선 처리)
├── FallDetector          # 모의 낙상 의심 판별
├── MobilityAssistant     # 모의 이동 허용/정지 판단
├── GuardianNotifier      # 로컬 알림 기록
├── MedicationManager     # 시각 기반 복약 알림
└── Guidance              # 시설·키오스크 안내 스크립트
```

## UML 대응

- 노인: 복약 알림, 실내 이동 보조, 편의시설 및 키오스크 안내
- 보호자: 위험 알림 수신 및 복약 일정 설정(일정 설정 UI는 향후 구현)
- 응급 지원 기관: 향후 승인된 통신/운영 절차로 연계(현재 자동 신고 기능 없음)

`include` / `extend`는 유스케이스 간 관계이고 Python 모듈 호출 관계와 일대일로 같지 않습니다.

## 안전 제약

낙상 의심은 의료 진단이 아닙니다. 보호자 알림은 로컬 이벤트로만 기록됩니다. 이동 코드는 모터를 구동하지 않습니다. 실제 로봇 배포 전 독립적인 하드웨어 비상 정지, 센서 장애 대비, 사용자 확인, 개인정보 보호 및 안전 검증이 필요합니다.
